# Misc samples

For anything that doesn't fit choir / horn / string — field recordings, textures,
one-shots, or custom sources for the user-sample sampler voice.

Files here can be loaded directly via the studio's Samples panel (drag + drop or
file picker). No naming convention required for one-shots; use the note-name
convention (C3.wav etc.) if you want Tone.Sampler pitch-mapping.
